Welcome to StudentHub

StudentHub is a unified web-based student portal designed for college students to easily manage their daily academic activities. Through this portal, enrolled students can view their personal profile, track semester course registrations, check subject-wise attendance, review pending assignments, view college circulars, download semester mark sheets, and check class timetables.

This website is built as a beginner-level college practical project demonstrating clean HTML5 semantic markup, structured tables, accessible form elements, and responsive CSS styling.

Passwords do not match.
Please select your course.
